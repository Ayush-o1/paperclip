
# Paperclip

A transactional e-commerce platform built with Node.js, Express, PostgreSQL, and Prisma.

## Overview

Paperclip provides a foundation for a commerce system with product
catalogue management, persistent shopping carts, transactional checkout,
inventory control, order management, and simulated payments.

## Technology

- Node.js and Express
- PostgreSQL and Prisma ORM
- JavaScript ES modules
- JWT-based authentication
- HTML, CSS, and vanilla JavaScript

## Development

Install dependencies:

```bash
npm install
```

Start the development server once the application entry point is available:

```bash
npm run dev
```

Run tests:

```bash
npm test
```

## Configuration

Use `.env.example` as the reference for required environment variables.
Create a local `.env` file when the application configuration is implemented.
Never commit credentials or production secrets.
